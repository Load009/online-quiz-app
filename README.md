
# QuizSpark - Online Quiz App

QuizSpark is a beginner-friendly online quiz application built
using HTML, CSS, and JavaScript.

## Features

- 10 general knowledge questions
- Four multiple-choice options per question
- Instant answer feedback
- Live score tracking
- Progress bar
- Final score and percentage
- Restart quiz option
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

online-quiz-app/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Click Start Quiz to begin.

No database or installation is required.

## Learning Objectives

This project demonstrates basic web development skills,
including HTML page structure, CSS styling, JavaScript
event handling, arrays, functions, DOM manipulation,
conditional statements, and score calculation.
